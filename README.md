# Desafio Ford: Calculadora de Preço Médio de Combustível ⛽

![Licença](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-concluído-brightgreen)

Uma aplicação web simples e interativa para calcular o preço médio de combustível, desenvolvida com HTML, CSS e JavaScript puro como parte do Desafio Ford.

---

## ✨ Sobre o Projeto

O objetivo desta aplicação é permitir que os usuários calculem de forma rápida e eficiente o preço médio de combustível com base nos valores de diferentes postos. O projeto foca em uma lógica de front-end robusta para proporcionar uma experiência de usuário fluida e direta, sem a necessidade de um backend.

**Link do projeto**: https://desafio-ford-seven.vercel.app/

---

## 🚀 Funcionalidades

- **[✔️] Geração Dinâmica de Campos:** Especifique a quantidade de postos de combustível e a aplicação criará os campos de entrada necessários.
- **[✔️] Cálculo Preciso:** Insira os valores e obtenha o preço médio do combustível instantaneamente.
- **[✔️] Validação de Dados:** Garante que apenas valores numéricos válidos (maiores que zero) sejam processados.
- **[✔️] Interface Intuitiva:** Design limpo e responsivo para fácil utilização em desktops e dispositivos móveis.
- **[✔️] Limpeza Rápida:** Um botão "Limpar" para resetar todos os campos e começar um novo cálculo.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais:

- **HTML5:** Para a estrutura semântica da página.
- **CSS3:** Para a estilização e responsividade da interface.
- **JavaScript (ES6+):** Para toda a lógica de manipulação do DOM, validação e cálculos.

## ▶️ Como Executar o Projeto

Como esta é uma aplicação puramente front-end, não há necessidade de um servidor web ou dependências complexas.

1.  **Clone o repositório:**

    ```sh
    git clone [https://github.com/viniciusdossantosss/Desafio-Ford.git](https://github.com/viniciusdossantosss/Desafio-Ford.git)
    ```

2.  **Navegue até o diretório do projeto:**

    ```sh
    cd Desafio-Ford
    ```

3.  **Abra no navegador:**
    Simplesmente abra o arquivo `index.html` em seu navegador de preferência (Google Chrome, Firefox, etc.).

E pronto! A aplicação estará funcionando.
